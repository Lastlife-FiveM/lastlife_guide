# Controls

All keys here are the **defaults**. If you've changed one, yours wins.

## Changing a key

Go to **Esc > Keybinds**, click a key and press the new one. Press **Apply changes**, and it saves when you close the menu with **Esc**. Keys that belong to GTA itself are under **Esc > Settings > Controls**.

{% hint style="info" %}
Some keys do more than one thing, depending on whether you're on foot, driving or aiming. If two get in each other's way, move one of them.
{% endhint %}

## Commands

Type these in the chat box. Commands work **without** a radio.

| Command | What it does |
| --- | --- |
| **Help and info** | |
| `/report` message | Reach the staff team |
| `/id` | Shows your player ID |
| `/class` | Shows your class and tier |
| `/showrank` | Shows your rank |
| **Talking** | |
| `/me` action | Shows what you're doing over your head |
| `/ooc` message | Out of character, to players close by |
| `/radio` | Open your radio |
| `/vol` 1 to 100 | How loud the radio is |
| **Your look** | |
| `/hat` `/glasses` `/mask` `/ear` `/neck` `/shirt` `/top` `/vest` `/gloves` `/watch` `/bracelet` `/bag` `/pants` `/shoes` `/hair` `/visor` | Take that piece off or put it back on |
| `/reloadskin` | Reload your look |
| `/clearstuckprops` | Remove something stuck to your body |
| `/weaponposition` | Move weapons and tools on your body |
| `/charmposition` | Move the charm on the weapon in your hands |
| **Emotes** | |
| `/e` name | Play an emote |
| `/em` | Emote menu |
| `/w` name | Walk style |
| `/f` name | Facial expression |
| **Vehicles** | |
| `/givekeys` id | Share your keys. No ID gives them to whoever is closest |
| `/getintrunk` | Climb into a trunk |
| `/togglevehradio` | Vehicle radio on or off |
| **Settings** | |
| `/resethud` | HUD back to default |
| `/hidecables` | Hide or show the power cables at bases |
| **Recording** | |
| `/record`, `/clip`, `/saveclip`, `/delclip` | Rockstar recorder: record, clip, save, throw away |
