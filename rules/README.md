# Server Rules

These rules keep the server fun. If the game lets you do something but a rule here says no, the rule wins. Not knowing a rule isn't an excuse, so give them all a read once.

## The short version

| | Rule | Read more |
| --- | --- | --- |
| 🤝 | Respect everyone. No hate, harassment or real-life threats. | [Conduct](conduct.md) |
| 🎭 | Stay in character and value your life. | [Roleplay](roleplay.md) |
| 🛡️ | No griefing in safe zones, with players, vehicles or zombies. | [Zones](zones.md) |
| 🌍 | Open world fights need roleplay. No killing on sight. | [PvP](pvp.md) |
| 🔴 | Red zones and the subway are Kill On Sight. | [Zones](zones.md) |
| 🧱 | Don't block the world with your base. | [Building](building.md) |
| 💣 | Raid fair. Take what you came for and go. | [Raiding](raiding.md) |
| 🔧 | No cheats, no exploits, no duping. | [Cheating](cheating.md) |
| 🎫 | Problem? Report it. Don't take revenge. | [Reports](reports.md) |

## How rules work

* **The spirit counts.** Hunting for loopholes is treated like breaking the rule.
* **Your crew counts.** You can be punished for helping someone break a rule or for keeping what they got from it.
* **Staff have the final say** on anything these pages don't cover.

{% hint style="info" %}
**We're in Closed Beta.** Rules can change. Big changes are announced in Discord.
{% endhint %}
