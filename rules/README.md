# Server Rules

These rules keep the server fun. If you can do something in game but it breaks a rule here, the rule wins.

| | The short version |
| --- | --- |
| 🤝 | Respect everyone. No hate, harassment or threats against real people. |
| 🛡️ | No griefing in safe zones, with players, vehicles or zombies. |
| 🌍 | Open world fights need roleplay. No killing on sight. |
| 🔴 | Red zones and extraction are Kill On Sight. |
| 🔧 | No cheats, no exploits, no duping. |
| 🎫 | Problem? Report it. Don't take revenge. |

{% hint style="info" %}
**We're in Closed Beta.** Rules can change. Staff have the final say when something isn't covered.
{% endhint %}
